冻结日期：2026-11-05（Asia/Shanghai）。机器可读版本为 `configs/experiment_protocol_v1.json`。

## 研究问题与主指标

在完全相同的数据、词表、网络宽度和训练预算下，比较字符级 LSTM 与 GRU 的测试集字符困惑度。主指标为三个随机种子的测试 PPL 均值和样本标准差；同时报告交叉熵、模型参数量、最佳轮次和训练时间。

## 固定设置

- 原始数据 SHA-256：`2798806f731be51e94323ba05326e4f59caecb8cb19a4403706f4b22d2c549db`。
- 划分 SHA-256：`fe21435dac6d84e59c69eb30f36afbf324d5dba1307db683896644c3ad6b7d76`。
- 词表 SHA-256：`e0ea6b0dce357b1b7b22bca82d3261e6ab9028d19cc272fde44510177d732883`。
- 数据划分种子 42，按完整诗篇划分 131/16/17，不重新抽取数据划分。
- 模型随机种子：42、43、44。
- 两模型均使用 embedding 128、hidden 256、2 层、dropout 0.2、单向结构。
- batch size 16；AdamW；学习率 0.001；weight decay 0.0001；梯度裁剪 1.0。
- 最多 50 轮；以验证集交叉熵早停，patience 8；保存验证交叉熵最低的 checkpoint。
- 测试目标包括字符与 `<eos>`，不计 `<bos>` 和 `<pad>`。每个模型完成验证集选择后只保存一次测试结果。

LSTM 与 GRU 采用相同维度，但门控结构不同，因此参数量不完全匹配。主表必须同时报告参数量，不能把结果解释成纯粹由单元类型造成的差异。

## 统计与生成报告规则

对每种模型报告三次测试 PPL 和交叉熵的算术平均值、样本标准差。训练曲线分别保留，汇总图显示各种子的轨迹或均值范围。统计 unigram/bigram 基线沿用已经按验证集选择的平滑系数。

文本生成使用 seed 42 checkpoint、固定提示“春、月、山”和固定解码种子；不按生成质量挑选模型或样本。五言/七言约束只作为表层格式实验。
