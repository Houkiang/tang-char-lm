# C 阶段开发验证记录

记录日期：2026-11-05（Asia/Shanghai）。这些是单种子开发验证结果，用于确认训练系统可工作；尚未评估测试集，不作为最终论文主结果。

## 实现内容

- 统一结构：字符嵌入、两层单向 LSTM 或 GRU、词表线性投影。
- 变长序列使用 `PackedSequence`，损失只计算真实目标字符和 `<eos>`。
- AdamW、梯度裁剪、验证集早停、最佳与最后 checkpoint、配置及环境记录。
- 每轮训练由 `seed + epoch` 确定 shuffle；checkpoint 保存 Python、NumPy、PyTorch 与 CUDA 随机状态。
- 已存在 run 不会被覆盖；只有配置完全一致并显式指定 `--resume` 才能恢复。

## 小样本过拟合检查

在最短训练诗篇的 17 个目标 token 上，使用较小的一层模型：

| 模型 | 初始 PPL | 达标步数 | 最终 PPL | 阈值 |
| --- | ---: | ---: | ---: | ---: |
| LSTM | 2404.56 | 16 | 1.1202 | 1.15 |
| GRU | 2395.03 | 11 | 1.1215 | 1.15 |

两种模型均通过，说明移位目标、反向传播与优化器路径能够学习。

## 单种子正式开发运行

共同设置：数据种子与模型种子 42，batch size 16，embedding 128，hidden 256，两层，dropout 0.2，AdamW 学习率 0.001、weight decay 0.0001，梯度裁剪 1.0，最多 50 轮，早停 patience 8。

| 模型 | 参数量 | 最佳轮次 | 完成轮次 | 最佳验证交叉熵 | 最佳验证 PPL |
| --- | ---: | ---: | ---: | ---: | ---: |
| LSTM | 1,812,875 | 20 | 29 | 6.3653 | 581.34 |
| GRU | 1,582,475 | 14 | 22 | 6.4887 | 657.69 |

LSTM 的完成轮次包含一次用于发现恢复逻辑问题的额外恢复轮次；最佳 checkpoint 未受影响。修复后，已经早停的 run 再执行 `--resume` 不再继续训练。

两个最佳 checkpoint 已在 CPU 上独立重算验证集：LSTM PPL 与记录完全一致；GRU 绝对差约 0.0015，属于 CPU/GPU 数值实现差异。测试集未被读取。

## 环境现象

在 RTX 5060 Laptop GPU 上，较长 CUDA RNN 训练完成并写出全部文件后，Windows 进程卸载阶段两次返回 `0xC0000409`；短检查、CUDA 张量计算和 CPU checkpoint 复算正常。该现象发生在结果持久化之后，但后续多种子实验前仍应评估更新 NVIDIA 驱动或 PyTorch CUDA 版本。当前 checkpoint 的 CPU 复算验证降低了结果损坏风险。
